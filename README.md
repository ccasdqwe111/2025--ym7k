交易与履约篇——门店自提与社区团购的完整闭环
门店自提：线上线下融合的关键
门店自提是 2025 年商城系统的高频功能。用户在线下单，选择附近门店或自提点，凭核销码到店取货。系统需支持 LBS 定位、门店列表、库存同步、营业时间、自提时效、核销记录。店长端可扫码核销、查看待自提订单、处理异常。对于连锁品牌，门店自提能降低物流成本、提升到店率、带动二次消费。系统还应支持“自提+配送”混合模式，用户可自由选择。

社区团购：预售、集单与团长体系
社区团购以社区为单位，团长组织预售，平台集中采购，次日送达自提点。系统支持团长开团、商品上架、佣金设置、订单汇总、分拣配送、自提核销。团长端可查看业绩、佣金、提现。平台端可管理多个社区、自提点、配送路线。社区团购的核心是“以销定采”，降低库存风险，适合生鲜、日用品、本地生活服务。系统需支持限购、起送价、配送范围、售后规则。

多人拼团：社交裂变与成团逻辑
多人拼团通过用户分享，邀请好友参团，达到人数后成团发货，未成团自动退款。系统支持普通拼团、阶梯拼团、老带新拼团、团长优惠。拼团与商品、库存、订单、支付、分销深度耦合。高并发下需防止超卖，成团后自动拆单、分账、通知。拼团适合拉新、清库存、打造爆款。后台可查看开团数、成团率、参团人数、转化率。

限时秒杀：脉冲流量与库存控制
限时秒杀通过限时低价制造紧迫感，带来脉冲流量。系统需独立秒杀库存池、倒计时、限购、防刷、队列削峰。秒杀开始前可预约提醒，开始后 Redis 原子扣减库存，异步落单。未支付订单超时回滚。秒杀与优惠券、会员价、分销佣金需明确叠加规则。后台可配置场次、商品、价格、库存、限购。秒杀是拉新促活利器，但需做好性能与风控。

订单、售后与结算
所有模式最终汇入统一订单体系。订单状态包括待付款、待发货、待自提、待收货、已完成、售后中、已取消。售后支持退款、退货、换货、部分退款。资金流涉及平台、商户、团长、分销员多方分账。系统需提供结算单、提现、对账、发票、税务合规。门店自提与社区团购的核销记录、配送记录、售后记录全程可追溯。

结语：门店自提与社区团购是 2025 商城系统的履约基础设施。只有把交易、库存、核销、分账、售后打通，才能让复杂模式稳定运行，让用户与商家都省心。
